IMPORTANT CMS LIMITATION
------------------------
admin.html is a credit-free browser-local CMS-style editor. It uses localStorage.
It can add/manage blogs and collection entries on the same browser/device.
Those changes do NOT publish to Netlify or automatically appear for other visitors.
A true shared CMS needs a publishing/backend workflow.
